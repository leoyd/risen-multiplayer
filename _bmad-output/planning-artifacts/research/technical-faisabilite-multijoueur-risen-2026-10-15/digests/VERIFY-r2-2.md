## New leads
- Desgeras d3d9.dll loader (Nexus Risen mod 58) loads any DLL from bin/DLLMods and claims compatibility with the 2023 64-bit Steam build. It is an alternative injection path to a custom loader.
- Steam depots and older builds can still be downloaded, besides the "original" beta branch.
- GitLab "Gothic Multiplayer Team" / g2o modules (Squirrel/Union templates, updated Jan 2026). This is a separate Gothic 2 Online ecosystem, worth checking for architecture reference.
- The repo README may now point to github.com/Pinemarten/GothicMultiplayer; check the canonical location.
- kcp-go docs warn that an unencrypted header is plaintext and can be tampered with (window size, RTT, FEC). This is security only, not interop.
